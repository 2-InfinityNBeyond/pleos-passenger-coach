# QA 결과 (2026-11-15)

- 대상: 눈치코치 0.1.0, debug 빌드(인증키 포함)와 release 빌드(인증키 없음)
- 환경: Pleos Connect Emulator v2.1.0(API 34), 화면 1024x768 160dpi, Vehicle SDK 2.3.2, NaviHelper SDK 3.0.5, Windows 11
- 방법: 가상 콘솔(Virtual Console)의 HTTP 명령으로 차량 신호를 바꾸고, 화면 캡처와 앱 로그로 확인했다. 실차에서는 확인하지 않았다.
- 표기: **통과** = 화면이나 로그로 직접 확인함 / **부분** = 일부만 확인함 / **미확인** = 상황을 만들지 못함

## 시나리오별 결과

| ID | 시나리오 | 확인한 방법 | 결과 |
|---|---|---|---|
| S0 | 동의 | 동의 전에는 차량 신호 로그가 없음. 운전자 체크 없이는 "동의하고 시작"이 눌리지 않음. "동의하지 않음"을 누르면 안내 문구가 나옴. 동의 뒤 신호 연결 로그 확인 | 통과 |
| S1 | 좌회전(데모) | 데모에서 안전벨트 → 전조등 → P에서 D → 좌회전 안내와 왼쪽 깜빡이 → 핸들 → 가운데 → 깜빡이 끔 순서로 해설이 나오고, 지도에 경로 선이 왼쪽으로 꺾여 보임 | 통과(데모) |
| S2 | 실제 신호(기어 P) | 가상 콘솔로 브레이크, 핸들, 방향지시등, 전조등, 와이퍼, 문을 바꾸면 계기판 그림과 해설이 따라 바뀜. 멈춘 상태에서 "방금 한 조작" 3개가 순서대로 나옴 | 통과 |
| S3 | 신호 끊김과 다시 시도 | 차량 서비스를 강제로 멈추면 약 10초 뒤 "차량 신호 없음 · N초 전"과 "다시 시도"가 뜨고 핸들 그림이 흐려짐. 앱은 종료되지 않음. "다시 시도"를 누르면 다시 연결되고 값이 돌아옴 | 통과 |
| S3b | 지원하지 않는 신호 안내 | 에뮬레이터는 핵심 신호를 모두 지원해 상황을 만들지 못함. 운전석 안전벨트 경고는 에뮬레이터가 지원하지 않는 것을 로그로 확인했고, 이때 앱은 그 항목만 건너뜀 | 미확인(안전벨트 건너뜀은 확인) |
| S4 | 센터 화면 주행 차단 | 기어를 D에 넣으면 속도 0이어도 시스템이 "주행 중에는 사용할 수 없습니다" 화면으로 앱을 가림. 기어 P로 돌아오면 앱이 다시 보임 | 통과(의도한 동작) |
| S5 | 데모 반복 | 데모를 7분 넘게 돌려 완전한 6회 반복을 로그로 비교. 6회 모두 해설 28개가 같은 순서로 나옴. 차이는 "내비가 우회전을 안내하고 4초/5초 뒤"의 초 숫자 한 곳뿐(시각 반올림). 앱 종료 없음 | 통과 |
| S6 | 물어볼 것, 설정 | ? 버튼을 누르면 개수가 올라가고 설정의 "물어볼 것 보기"에 쌓임. 연습 상황, 코치 모드, 학습 기록, 이전 화면 전환, 동의 철회(기록과 설정 삭제 뒤 첫 화면) 확인 | 통과 |
| S7 | 야간 화면 | 야간 모드로 바꾸면 어두운 화면으로 바뀌고 해설이 유지됨 | 통과 |
| S8 | 내비 안내와 지도 | 내비 경로가 있을 때 다음 안내 칩(화살표, 남은 거리)과 그다음 안내 2개가 표시됨. 주변 길과 계산한 경로 선이 지도에 그려짐 | 통과(목적지는 개발용 명령으로 지정) |
| S9 | 신호등 잔여시간 | 위치를 울산의 교차로로 지정하면 직진과 좌회전 신호의 색과 남은 초가 표시되고 초가 줄어듦 | 통과(방향은 가정) |
| S10 | 후진 주차(데모) | 기어 R에서 합성 후방 화면으로 바뀌고 가이드선이 핸들에 따라 휨. "핸들을 왼쪽으로 한 바퀴 돌려 놓고 브레이크를 뗐어요" 등 해설 확인 | 통과(데모) |

## 자동 테스트
- 단위 테스트 57개 통과: 해설 규칙과 되짚기 25, 상태 판정 9, 지도 좌표 5, 경로와 표지판 5, 후방 화면 계산 5, 신호등 해석 4, 학습 기록 2, 알아 두기 2
- release APK에 인증키가 들어 있지 않은 것을 빌드 때마다 확인

## 확인하지 못한 것
- 실차 동작 전부(신호 값의 범위와 주기, 동승석 창, 주행 중 표시)
- 1024x768 외의 화면 크기. 좁은 창에서는 핸들을 줄이고 각도 숫자를 빼도록 만들었으나 실제로 띄워 보지는 못함
- 지원하지 않는 신호 안내, 운전석 안전벨트 경고(에뮬레이터 미지원)
- 실제 신호로 달리는 장면(센터 화면은 기어 D에서 차단). 달리는 장면은 데모로만 확인
- 신호등의 방향(북쪽, 남쪽 칸)이 실제 교차로와 맞는지
- 해설과 알아 두기 문구의 전문가 검수, 법령 인용의 현행 조문 대조

## 이 검사로 찾아 고친 결함
| 결함 | 찾은 방법 | 조치 |
|---|---|---|
| 데모 두 번째 반복부터 "운전자가 안전벨트를 맸어요"가 나오지 않음: 기어와 함께 안전벨트·전조등이 한꺼번에 바뀌면 일부 상태를 놓침 | S5 데모 반복 비교 | 모든 값을 매번 끝까지 반영하고 할 말은 줄을 세워 두도록 수정, 회귀 테스트 추가 |
| 줄 세워 둔 해설이 한참 뒤(좌회전이 끝난 뒤)에 나옴 | S5 재검사 | 1.2초 틈을 두고 이어서 말하고, 5초 넘게 밀린 것은 버리도록 수정, 테스트 추가 |
| 후진 화면에서 알아 두기 카드가 "시뮬레이션" 표시를 가림 | 영상 프레임 확인 | 표시를 왼쪽 아래로 옮김 |
| 신호등 칩에 "참고용" 표시가 빠짐 | 화면 확인 | "참고" 표시 추가 |
| 신호 끊김 알림이 다음 안내 칩과 겹침 | S3 화면 확인 | 알림을 오른쪽 위로 옮김 |
| 공용 서버가 느려 데모 지도에 길이 나오지 않음 | 영상 프레임 확인 | 데모 구간의 길 자료를 앱에 넣음(© OpenStreetMap contributors) |

## 알려진 문제
| 문제 | 영향 | 상태 |
|---|---|---|
| 방향지시등을 켜면 Pleos 시스템이 후측방 카메라 창을 앱 위에 띄움 | 센터 화면에서 깜빡이를 켠 동안 앱이 가려짐 | 시스템 동작이라 앱에서 막을 수 없음. 동승석 창에서의 동작은 확인 필요 |
| 에뮬레이터가 목적지 좌표를 0으로 줌 | 에뮬레이터에서는 내비 앱으로 목적지를 정해도 경로 선이 그려지지 않음 | 개발용 명령으로 목적지를 주면 그려짐. 실차는 확인 필요 |
| 길 모양 공용 서버가 느리거나 실패함 | 처음 가는 곳에서 지도의 길이 수십 초 늦게 나오거나 안 나옴(경로 선과 내비 안내는 정상) | 받은 자리는 기기에 저장해 다시 씀. 출시 전 지도 자료 서비스 교체 필요 |
| 주차한 채 오래 있다가 깜빡이를 켜면 "내비가 안내하고 100초 뒤"처럼 큰 숫자가 나옴 | 틀린 말은 아니지만 어색함 | 미수정 |
| 지도의 경로 선이 운전자 내비의 길과 다를 수 있음 | 다음에 할 일은 내비 안내(칩)가 기준이라 영향 제한적 | SDK가 경로 좌표를 주지 않아 생기는 한계 |
