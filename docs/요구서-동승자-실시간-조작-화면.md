# 요구서 v0.1: 동승자 실시간 조작 화면

- 앱(임시 이름): 이세계주행천재 / 참가: 개인, 일반 부문
- 작성일: 2026-11-13 / 상태: **v0.1 확정** (사용자 확정 2026-11-13 밤). 시동 꺼짐은 표기하지 않고 신호가 끊기면 "차량 신호 없음"으로 표시 **[결정]**
- 표기: **[확인됨]** 직접 실행/라이브러리로 확인, **[확인 필요]** 아직 모름, **[결정]** 사용자 확정, **[제안]** Claude 제안
- 근거 자료: `docs/기술검증_2026-11-13.md`, `02_기획_진행노트.md`

## 1. 한 문장 문제
면허가 없는 동승자(예비 운전자)는, 가족 차에 타서 도로를 보는 동안, 운전자의 조작(핸들·깜빡이·브레이크)과 판단이 눈에 보이는 정보로 전달되지 않고 교재에는 실제 장면이 없기 때문에, 운전 조작을 장면과 연결해 배우지 못한다. 그 결과 **연수 비용**(참고: 한 학원의 정규 과정 858,000원, 사설 연수 요금은 [확인 필요])에 기대고 첫 운전에서 당황하게 된다.
- 지금의 대안: 학원, 시뮬레이터 앱(도로로), 연수 매칭 앱(운전결심, 운전선생), 유튜브

## 2. 목표 (1개)
면허 준비생이 가족 차에 동승하는 동안, **운전자의 조작(핸들 각도, 깜빡이, 브레이크, 기어)과 내비 안내를 한 화면에서 실시간으로 보고**, 그 조작이 왜 필요한지 짧은 해설로 이해한다.

## 3. 사용자
1순위 면허 준비생 / 2순위 면허 직후 초보 운전자 / 부가: 동승 코치(연수 강사가 초보 운전자 연수 중 함께 보는 보조 장비) **[결정]**

## 4. 바꿀 행동 (이 앱이 있기 전 → 후)
| | 앱 없음 | 앱 있음 |
|---|---|---|
| 동승자의 자세 | 운전자의 손과 발을 보려고 몸을 돌리거나 기울인다(사용자 추측, [확인 필요]) | **가만히 앉아 앞을 보며** 앱 화면을 본다 |
| 볼 수 있는 것 | 운전자 상체까지. 페달, 핸들 각도는 안 보임 | 핸들 각도, 방향지시등, 브레이크 켜짐, 기어가 화면에 표시 |
| 내비와 조작의 연결 | 내비 화면 따로, 운전자 따로 봐야 함 | **내비 안내(예: 좌회전)와 실제 조작(깜빡이 시점, 핸들 각도)을 한 화면에서 대조** [확인 필요: 내비 안내 데이터 실제 필드] |
| 학습 | 문제집의 글자 설명 | 실제 도로 장면 + 같은 시점의 조작 데이터 |

## 5. 화면 방식
- 전제 **[결정]**: **동승자 전용 디스플레이**에서 실시간 표시. 위치는 뒷좌석 → 조수석 → 태블릿으로 확장하며 기획서에는 "향후 계획"으로 명시(공지상 허용)
- **[확인됨]** 에뮬레이터에서 기어 D, 40km/h일 때 **센터 화면의 앱은 "주행 중에는 사용할 수 없습니다"로 차단**(DO 미선언), **DISPLAY2 창의 앱은 그대로 표시**(1회 확인). 실차 동작은 [확인 필요]
- 센터 화면(운전자 쪽)에는 주행 중 앱이 뜨지 않으며, 이 앱은 운전자 화면을 사용하지 않는다

## 8. 기대 결과
### 정상
- 운전자가 핸들을 돌리거나 깜빡이를 켜거나 브레이크를 밟거나 기어를 바꾸면, 동승자 화면의 해당 표시가 **바뀐다**. 갱신 지연 목표는 **1초 이내** [확인 필요: 측정 전]
- 내비 경로가 있으면 다음 안내(예: "좌회전")와 현재 조작이 함께 표시된다 [확인 필요]
- 조작 이벤트가 감지되면 해설 문장 하나가 표시된다(한 번에 한 문장, 시선 부담 최소)
### 빈 상태 (값이 없을 때는 "값 없음"이라고 쓰지 않고 **차량 상태를 표기**) **[결정]**
| 상황 | 표기 |
|---|---|
| 기어 P | "주차 중" |
| 기어 N | "중립" |
| 기어 D/R이지만 조작 변화가 없고 브레이크가 켜져 있음 | "정차 중" (판정 규칙은 spec에서 확정) |
| 시동 꺼짐 | **표기하지 않음 [결정]**: 공개 SDK에 신호가 없어 추정이 틀릴 수 있음. 모든 신호가 끊기면 **"차량 신호 없음"** 으로 표시 |
| 내비 경로 없음 | "내비 안내 없음" 표시, 나머지 조작 표시는 정상 |
### 실패
| 상황 | 동작 |
|---|---|
| 해당 신호를 차량이 지원하지 않음(`checkXxxCapabilities`가 NONE) | "이 차량은 ○○ 신호를 제공하지 않아요", 그 항목만 비활성, 나머지는 정상 |
| 신호가 끊김(구독 콜백 중단) | **"차량 신호 없음"** + 마지막 값을 흐리게 표시 + 마지막 수신 시각, 앱은 종료되지 않음 |
| SDK 초기화 실패 | 안내 문구와 다시 시도 버튼 |
| 동의하지 않음 | 시작하지 않고 설명 화면 유지 |

## 9. 하지 않을 것
1. **차량을 제어하지 않는다** (읽기 전용) **[결정]**
2. **운전자를 방해하지 않는다**: 운전자에게 경고, 지시, 알림을 하지 않고 센터 화면에 표시하지 않는다 **[결정]**
3. **운전 점수나 평가를 하지 않는다** **[결정]**
4. 주변 차량(끼어들기, 사각지대)을 **감지하지 않는다**: 공개 SDK에 없음 **[확인됨]**. ADAS SDK가 공개되면 향후 확장
5. 가속페달과 속도를 Vehicle SDK로 표시하지 않는다 **[확인됨]** (속도는 내비 값 확인 후 재검토)
6. 주행 중 사용자 입력과 터치를 요구하지 않는다
7. 주행 데이터를 **저장하거나 외부로 전송하지 않는다**(이번 버전은 기기 안에서만, 기록은 확장)

## 12. 확인 필요 (남은 불확실성)
1. 구독 콜백의 **실제 지연**(1초 이내 가능한가)
2. NaviHelper **TBT/DrivingInfo의 실제 필드**, 에뮬레이터에서 경로를 설정해 값이 나오는가, 속도 포함 여부
3. **시동 꺼짐** 판정 방법(공개 신호 없음)
4. 브레이크 신호가 **켜짐/꺼짐 외에 정도를 주는가**(샘플에서는 boolean)
5. DISPLAY2에서 주행 중 표시되는 동작이 **실차 정책과 같은가**
6. 앱 카테고리 선언, DO(주행 최적화) 선언 정책
7. 에뮬레이터 안정성(이 PC에서 멀티 디스플레이 옵션을 켜면 반복 종료)
8. 사설 도로연수 요금(사업성 숫자)
9. 코치 해설 규칙의 정확성(강사 검수 필요)
