# 여정 · IA · 화면 흐름 v0.1 (요구서 v0.1 기준)

앱(임시 이름): 이세계주행천재 / 표시 위치: **동승자 전용 디스플레이**(확장 전제). 현재 구현은 에뮬레이터 기준 1024x768 또는 1280x720 가로.

## 1. 여정 (핵심 사용자 여정, CUJ)
| ID | 여정 | 사용자 | 흐름 |
|---|---|---|---|
| CUJ-01 | 첫 실행과 동의 | 동승자 | 앱 열기 → 안내(무엇을 보여주는 앱인지, 운전자 화면 비사용) → 면책 동의 → 대기 화면 |
| CUJ-02 | **주행 중 실시간 학습(좌회전)** | 동승자 | 내비가 "좌회전" 안내 → 운전자가 깜빡이 → 핸들을 돌림 → 해제 → 화면에 단계가 차례로 표시 + 해설 한 문장 |
| CUJ-03 | 정차와 재출발 | 동승자 | 기어 P "주차 중" → D로 전환 → 실시간 화면 → 브레이크 켜짐 "정차 중" |
| 에러 | 신호 끊김, 지원 안 됨, 초기화 실패 | 동승자 | "차량 신호 없음" 또는 항목별 안내, 앱은 종료되지 않음 |

### 감정 곡선 (CUJ-02, 사용자 추측 기반 [확인 필요])
기대(오늘은 뭘 볼까) → 집중(운전자의 조작이 화면에 뜸) → 이해(해설 한 문장) → 안심(운전자가 안 말해도 알 수 있음)

## 2. 정보 구조(IA)
```
이세계주행천재 (앱)
├─ S0 안내·동의            (첫 실행 1회)
├─ S1 대기 화면            (기어 P, N 또는 정지: 상태 문구 + 오늘의 안내)
├─ S2 실시간 조작 화면 ★   (핵심, 한 화면)
│    ├─ 핸들 각도 (그림 + 숫자)
│    ├─ 방향지시등 (좌/우)
│    ├─ 브레이크 (켜짐/꺼짐)
│    ├─ 기어 (P R N D)
│    ├─ 내비 다음 안내 [확인 필요: 값이 나올 때만]
│    └─ 해설 한 문장
├─ S3 신호 없음/오류       ("차량 신호 없음", 항목별 미지원, 재시도)
└─ (개발용) 데모 모드      (시나리오 재생, 사용자에게는 숨김 또는 설정 안)
```
용어: 화면에는 "급", "점수", "위험" 같은 평가 단어를 쓰지 않는다(요구서 하지 않을 것 3).

## 3. 화면 흐름
```
첫 실행 ─▶ S0 안내·동의 ─(동의)─▶ S1 대기
                │(비동의)           │(기어 D/R 이고 신호 정상)
                ▼                   ▼
          설명 유지            S2 실시간 조작 ◀──┐
                                   │ │            │
              (신호 끊김)◀─────────┘ └─(기어 P/N, 정지)─▶ S1 대기
                   ▼
              S3 차량 신호 없음 ─(신호 복구)─▶ 직전 화면
```

## 4. 상태와 문구 (요구서 8절과 1:1)
| 조건 | 화면 | 문구 |
|---|---|---|
| 기어 P | S1 | 주차 중 |
| 기어 N | S1 | 중립 |
| 기어 D/R + 브레이크 켜짐 + 핸들 변화 없음 | S2 | 정차 중 |
| 기어 D/R, 정상 | S2 | (실시간 표시) |
| 모든 신호 끊김 | S3 | 차량 신호 없음 |
| 특정 신호 미지원 | S2 항목별 | 이 차량은 ○○ 신호를 제공하지 않아요 |
| 내비 경로 없음 | S2 내비 카드 | 내비 안내 없음 |

## 5. S2 와이어프레임 (가로 1280x720 기준 개략)
```
┌──────────────────────────────────────────────────────────────┐
│ 이세계주행천재                        [기어  P R N [D]]       │
├───────────────┬───────────────────────┬──────────────────────┤
│   핸들        │   내비 다음 안내      │  방향지시등  ◀ ▶      │
│   ( 그림 )    │   ⬅ 좌회전 120m       │                      │
│   -45°        │   [값이 있을 때만]    │  브레이크  ●켜짐     │
├───────────────┴───────────────────────┴──────────────────────┤
│ 해설: 방향지시등을 켠 뒤 핸들을 왼쪽으로 돌렸어요.            │
└──────────────────────────────────────────────────────────────┘
```
- 큰 글씨, 큰 터치 영역(터치 입력 자체는 거의 없음), 높은 대비, 움직임 최소
- 해설은 한 번에 **한 문장**, 새 이벤트 전까지 유지(깜빡이는 효과 없음)
- 색만으로 구분하지 않기(아이콘+글자 병기)
- 참고: Pleos 주행 안전 가이드(주행 중 영상, 애니메이션 최소, 큰 터치 영역, 최소 텍스트)

## 6. 이벤트와 해설 규칙 초안 (규칙 기반, 강사 검수 필요 [확인 필요])
| 이벤트 | 조건 | 해설 예 |
|---|---|---|
| 방향지시 켜짐 | TurnSignal = LEFT/RIGHT | "왼쪽(오른쪽) 깜빡이를 켰어요." |
| 회전 시작 | 방향지시 켜짐 이후 핸들 각도 변화가 임계값 초과 | "깜빡이를 켠 뒤 핸들을 돌렸어요." |
| 직진 복귀 | 핸들이 중앙 근처로 복귀 | "핸들이 다시 가운데로 돌아왔어요." |
| 브레이크 켜짐/꺼짐 | Brake true/false | "브레이크를 밟았어요 / 뗐어요." |
| 내비 안내 → 조작 | TBT 안내 시점 이후 깜빡이까지의 시간 | "안내 후 N초 뒤 깜빡이를 켰어요." [내비 값 확인 후] |
- 임계값(핸들 각도, 시간)은 상수로 분리하고 spec에서 확정
